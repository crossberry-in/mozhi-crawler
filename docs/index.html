Installation & Setup

Install Mozhi Crawler using the official Mozhi package manager:

mz install @crossberry-in/mozhi-crawler

Or add it directly to your project's package.toml manifest:

[dependencies]
crawler = "@crossberry-in/mozhi-crawler"

Advanced Web Spider

The crawler.spider(config) function powers large-scale, controlled site crawls with strict resource constraints and detailed link graph discovery.

import crawler

let result = crawler.spider({
    url: "http://127.0.0.1:8089/",
    live_fetch: true,
    save_db: true,
    cache_dir: ".crawler_cache",
    max_pages: 50,
    max_depth: 3,
    same_domain: true,
    same_origin: false,
    max_external_domains: 5,
    max_pages_per_domain: 20,
    max_links_per_page: 100,
    max_total_requests: 100,
    max_redirects: 5,
    max_response_bytes: 2000000,
    respect_robots: true,
    allow_private_ips: true
})

echo("Spider Success: " + string(result.ok))
echo("Pages Crawled:  " + string(result.pages.len()))
echo("Total Requests: " + string(result.stats.total_requests))
echo("Stopped Reason: " + result.stopped_reason)

Persistent Storage & Offline Caching

When save_db: true is passed, page results, content fingerprints, and non-sensitive metadata are persisted into either a filesystem JSON cache or native SQLite database.

Reading in Offline Mode

# Zero network access guaranteed:
let offline_res = crawler.spider({
    url: "http://127.0.0.1:8089/",
    offline: true,
    cache_dir: ".crawler_cache",
    max_pages: 5
})

if offline_res.ok {
    echo("Read " + string(offline_res.pages.len()) + " pages from cache.")
    echo("Network requests made: " + string(offline_res.stats.total_requests)) # 0
} else {
    echo("Error: " + offline_res.errors[0].message)
}

Declarative Schema Extraction

Extract structured records, nested catalogs, and list views using intuitive schema mappings:

let schema = {
    "store_name": "header h1",
    "products": {
        "selector": "article.product-item",
        "multiple": true,
        "fields": {
            "id": { "attribute": "data-id" },
            "title": "h2.prod-title",
            "price": "span.prod-price",
            "url": { "selector": "a.buy", "attribute": "href" }
        }
    }
}

let page = crawler.scrape("http://127.0.0.1:8089/products")
let catalog = crawler.extract(page.doc, schema)

echo("Store: " + catalog.store_name)
for p in catalog.products {
    echo(p.title + " (" + p.price + ")")
}

Link Graph & Website Analysis

The spider automatically captures the directed link topology of the crawl space. Analyze incoming and outgoing link distributions, detect redirect chains, identify duplicate content, and export graphs to JSON and CSV:

let outgoing = crawler.get_outgoing_links(result, "http://127.0.0.1:8089/")
let incoming = crawler.get_incoming_links(result, "http://127.0.0.1:8089/about")
let duplicates = crawler.find_duplicate_content(result)
let broken = crawler.find_broken_links(result)

# Export graph topology
crawler.export_graph_json(result, "graph.json")
crawler.export_graph_csv(result, "graph.csv")

Security & SSRF Protection

Mozhi Crawler enforces strict SSRF protections on every network hop. By default, requests to internal and unroutable destinations are blocked before network transmission:

Target Subnet / Range Status Description
127.0.0.0/8, localhostBlockedIPv4 loopback interface.
::1, [::1]BlockedIPv6 loopback interface.
10.0.0.0/8BlockedRFC 1918 Private Network.
172.16.0.0/12BlockedRFC 1918 Private Network (172.16 - 172.31).
192.168.0.0/16BlockedRFC 1918 Local Area Network.
169.254.169.254BlockedCloud Metadata Endpoint (AWS, GCP, Azure).
0.0.0.0/8BlockedCurrent local network source.
