cURL Chat Completion with nvidia/gpt-oss-20b

Developers can query the documentation assistant or BlockRun models directly from terminal or scripts using the standard OpenAI-compatible completions endpoint:

curl -sS https://blockrun.ai/api/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_BLOCKRUN_API_KEY' \
  -d '{
    "model": "nvidia/gpt-oss-20b",
    "messages": [
      {
        "role": "system",
        "content": "You are the Mozhi Crawler Docs Assistant. Use the official documentation to answer questions about web crawling, spidering, and multi-agent research."
      },
      {
        "role": "user",
        "content": "Explain how to configure BlockRun provider in Mozhi crawler with free_only policy."
      }
    ]
  }'

In pure Mozhi code, the equivalent call is executed natively without external tools:

import crawler

let mgr = crawler.init_provider_manager({
    default_provider: "blockrun",
    free_only: true
})

let res = crawler.call_chat_completion(mgr, "blockrun", {
    model: "nvidia/gpt-oss-20b",
    messages: [
        { "role": "system", "content": "You are the Mozhi Crawler Docs Assistant." },
        { "role": "user", "content": "How do I run multi-agent research?" }
    ]
})

echo(res.content)

Multi-Agent Research Pipeline Architecture

Six specialized, bounded agents coordinate sequentially across link discovery, crawling, extraction, verification, and synthesis—governed by shared budgets and strict evidence provenance.

Multi-Agent Research in Action

Execute research with a single unified call: crawler.research(config). All claims reference source URLs with verified HTTP response codes.

import crawler

let result = crawler.research({
    query: "What developer products and hardware does Mozhi offer, and what are their prices?",
    url: "https://example.com/products",
    provider_config: {
        default_provider: "blockrun",
        free_only: true
    },
    max_pages: 5,
    save_cache: true,
    cache_dir: ".crawler_cache"
})

echo("Research Completed: " + string(result.ok))
echo("Answer:\n" + result.answer)

# Render Categorized Terminal Tables
crawler.print_research_tables(result)

AGENT 1 & 2 Discovery

Extracts research goals, generates targeted search queries, parses sitemaps, and ranks candidate links by relevance.

AGENT 3 & 4 Collection

Fetches HTML, extracts headings, tables, JSON-LD, metadata, and stores atomic factual claims with provenance URLs.

AGENT 5 & 6 Synthesis

Corroborates claims, flags conflicts, and produces evidence-grounded answers citing verified source URLs.

Custom LLM Provider Configuration

Configure OpenAI-compatible endpoints, custom headers, and API keys without modifying source code. Keys and bearer tokens are automatically redacted in diagnostics and logs.

let mgr = crawler.init_provider_manager({
    default_provider: "blockrun",
    free_only: true,
    auto_model: true,
    auto_fallback: true,
    providers: [
        {
            id: "blockrun",
            name: "BlockRun",
            base_url: "https://blockrun.ai/api/v1",
            api_format: "openai",
            api_key_env: "BLOCKRUN_API_KEY",
            model_discovery: true,
            enabled: true
        },
        {
            id: "local-llm",
            name: "Local vLLM / Ollama",
            base_url: "http://127.0.0.1:8000/v1",
            api_format: "openai",
            model_discovery: true,
            enabled: true
        }
    ]
})

# Dynamic Model Discovery & Provider Health Check
let health = crawler.test_provider_connection(mgr, "blockrun")
echo("Provider Status: " + string(health.status) + " (" + string(health.latency_ms) + " ms)")

High-Performance Web Spider Engine

Breadth-first search queue with URL normalization, crawl depth, domain budgets, SSRF protection, content fingerprinting, and link topology analysis.

let crawl_result = crawler.spider({
    url: "https://example.com",
    live_fetch: true,
    save_db: true,
    max_pages: 50,
    max_depth: 3,
    same_domain: true,
    max_total_requests: 100
})

let broken = crawler.find_broken_links(crawl_result)
let duplicates = crawler.find_duplicate_content(crawl_result)

crawler.export_graph_json(crawl_result, "graph.json")
crawler.export_graph_csv(crawl_result, "graph.csv")

Complete Public API Reference (v1.3.1)

All 28 functions are exported by @crossberry-in/mozhi-crawler and ready to import directly.

Module Category Function Signature Description
RESEARCH crawler.research(config: map) -> map Orchestrates complete multi-agent research workflow with LLM provider.
RESEARCH crawler.validate_research_result(res) -> map Validates research result against documented JSON contract schema.
RESEARCH crawler.print_research_tables(res: map) Renders categorized ASCII terminal tables for findings, sources, and agents.
PROVIDER crawler.init_provider_manager(cfg) -> map Initializes LLM provider manager from map or configuration file.
PROVIDER crawler.add_provider(mgr, prov: map) -> map Registers or updates custom LLM provider endpoint.
PROVIDER crawler.discover_models(mgr, prov_id, store) -> array Fetches dynamic model catalog from provider GET /models.
ROUTING crawler.select_model_for_task(mgr, id, task, vis) Selects best eligible model honoring task requirements and free-only policy.
ROUTING crawler.call_chat_completion(mgr, id, opts) Executes chat completion with OpenAI-compatible payload.
ROUTING crawler.call_chat_completion_with_fallback(mgr, opts) Executes chat completion with retry, backoff, and fallback across providers.
SPIDER crawler.spider(config: map) -> map Breadth-first search web crawler with limits, storage, and link graph.
DOM crawler.parse_html(html: str) -> map Parses HTML string into node-keyed DOM tree.
DOM crawler.query_selector(doc, sel: str, ctx) -> int Returns node ID of first matching element.
SECURITY crawler.validate_target_url(url, allow_priv) -> map Validates URL against SSRF, loopback, private subnets, and schemes.
STORAGE crawler.init_storage(opts: map) -> map Initializes unified filesystem JSON or SQLite persistent cache.
